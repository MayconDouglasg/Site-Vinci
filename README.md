# Projeto Vinci

Site de apresentação da Vinci, uma marca de carros elétricos, criado a partir de um layout no Figma.

O projeto permite conhecer a marca, explorar os modelos e ver detalhes dos veículos, como design, autonomia e recursos. Também conta com uma seção de perguntas frequentes e informações sobre serviços.

O visual se adapta a computadores e celulares para facilitar a navegação.
